This browser build has one local database instance per tab. User and session counters describe this instance; a future multi-user host can use the same status schema with authenticated identities. “Busy” is measured request activity, not an invented CPU percentage.

Local workspaces

Snapshots use versioned IndexedDB generations. The last three versions are retained for recovery; large binary snapshots use OPFS when the browser supports it, while IndexedDB keeps their metadata and recovery pointers. Clearing this site’s browser data removes every workspace.
